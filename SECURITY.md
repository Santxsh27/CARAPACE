# Security policy

CARAPACE is currently a pre-release research and hackathon project. It must be
used only with synthetic data and systems that the operator is authorised to
test.

Do not submit real payment credentials, PINs, OTPs, CVVs, passwords, signing
keys, customer records, or production transaction evidence to this repository.

Until a private disclosure channel is configured, do not publish suspected
security vulnerabilities in a public issue. Contact the repository owner
privately and include the affected version, reproduction conditions, expected
impact, and a minimal synthetic proof.

The project does not authorise testing against banks, wallets, payment rails,
merchants, or customer accounts without their explicit permission.
